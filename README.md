# Умный поиск по книгам

Сервис для поиска фрагментов текста и ответов на вопросы по загруженным книгам в формате `.txt`.  
Реализован на чистом Python без внешних зависимостей.

## Стек технологий

- **Язык:** Python 3.6+
- **Библиотеки:** только стандартные (`os`, `re`, `math`, `collections`, `json`)
- **Метод поиска:** TF‑IDF + косинусное сходство
- **Интерфейс:** консольное меню

## Как запустить сервис

1. Убедитесь, что установлен Python 3.6 или новее.
2. Скачайте файл `reader.py` (или скопируйте код из репозитория).
3. Откройте терминал в папке с файлом и выполните:
   ```bash
   python reader.py
